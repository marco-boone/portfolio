## Overview

The glove reads hand motion and finger bends, recognizes gestures, and uses them to control audio: start a recording, play it back, or stop. Everything runs bare metal with no RTOS, so all peripheral timing is handled with interrupts and DMA.

## Gesture control

Sensor reads are triggered by a timer interrupt. Each sample is checked against simple thresholds, and a small state machine turns gestures into actions.

<GloveStateMachine>How gestures move the glove between idle, recording, and playback.</GloveStateMachine>

## Key features

- No RTOS: 6+ peripherals over SPI, I2C, and UART, all in bare-metal C
- Interrupt-driven gesture recognition
- DMA for audio sampling so the CPU stays free for gesture processing {/* FILLER */}
- Recordings saved to an SD card {/* FILLER */}
