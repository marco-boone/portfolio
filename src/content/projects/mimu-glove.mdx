## CONTEXT

This glove was built for my EECS 373 final project. It was an attempt to recreate the Imogen Heap musical glove: a wearable glove that lets the user record, loop, edit, and play back music using gesture controls.

## DESIGN

The system is split into two STM32 projects: the glove reads the hand and sends commands, and the board does all of the audio. The two talk wirelessly through a pair of ESP32s.

<GloveSystemDiagram>glove on top, board on the bottom - each wire is colored by its bus</GloveSystemDiagram>

- **Glove** (NUCLEO-L432KC): reads 4 analog inputs (flex/force sensors) via ADC + DMA, reads an I2C accelerometer for hand orientation, builds a small command packet, and transmits it over UART.
- **Board** (STM32L4R5ZI): receives the command packet and transitions through an FSM accordingly. Recording is done over I2S with a MEMS microphone, it reads and writes an SD card over SPI, and playback goes out through the DAC to an audio jack.

### Glove → board packet

| byte | name | meaning |
|---:|---|---|
| 0 | `mode` | mode index (0..3), advanced by a tap on ADC channel 0 |
| 1-3 | `flex1`-`flex3` | 1 if that finger's ADC channel is past its threshold |
| 4 | `fingers_up` | 1 if the accelerometer says fingers up |
| 5 | `palm_up` | 1 if the accelerometer says palm up |
| 6 | `roll_x_1to10` | roll around the X axis, mapped to 1..10 |

### Controls

- Lift hand up and bend fingers to record a loop
- Return hand to regular position to stop recording
- Lift hand and bend fingers again to record and layer a new loop
- Tilt hand left and right to adjust the roll value (1..10)
- Flip hand over to delete the current loop
- Tap to switch between modes
